# Audio provenance

These 58 WAV files are synthesized Japanese study audio, rendered offline with the installed Windows voice Microsoft Haruka Desktop (ja-JP). They are not recordings of a native speaker. The curriculum supplies the original Japanese transcripts and explicit kana readings, including contextual hours and dates. WAV PCM is 16 kHz, 16-bit, mono.

The app serves the files directly through GitHub Pages. Playback does not contact a speech service, require an API key, or depend on a Japanese voice installed on the learner's device. Audio is loaded only when requested.

Human recordings can replace these clips: update the item's `audio.src` and `audio.kind` to `recording`, retaining the matching transcript and exercise IDs. Synthesis is a temporary listening foundation; native recordings and pronunciation review remain future content work.
